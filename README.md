## Featured Project

### [AFO — Advanced File Organizer](https://github.com/Himath-Rajapaksha/AFO)

<div align="center">

<img src="https://github.com/Himath-Rajapaksha/AFO/blob/main/Screenshots/Gif/Prev-AFO.gif?raw=true" width="700" alt="AFO Demo" />

</div>

**Stop drowning in Downloads. Let your files sort themselves.**

A cross-platform desktop app that watches, sorts, renames, and de-duplicates your files automatically — built with Tauri v2, React, and Rust.

<table>
<tr>
<td width="50%" valign="top">

**Organize**
- Smart Sort — by extension, date, or metadata
- Batch Rename — pattern templates with live preview
- Visual Rule Builder — drag-and-drop conditions
- Metadata-Aware — EXIF and audio tag reading

</td>
<td width="50%" valign="top">

**Automate & Protect**
- Real-Time Watching — organize as files land
- Scheduled Runs — cron-based automation
- Duplicate Detection — blake3 hashing
- Full Undo/Redo — every operation is reversible

</td>
</tr>
</table>
